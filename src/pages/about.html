About

dorh.fyi is a small set of tools built by Dor, a system administrator and information security practitioner, for the tasks that come up every week: reading a suspicious email's headers, working through a pile of DMARC reports, checking a certificate, moving cron jobs to systemd, or figuring out whether two subnets overlap.

The rule for every tool is that it must work fully offline once loaded and must never need your data on a server. If a feature can't meet that rule, for example live DNS lookups, it isn't added.

Found a bug or a header format the analyzer mangles? Feedback is welcome.
