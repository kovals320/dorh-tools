Privacy

Every tool on this site except What Is My IP runs entirely in your browser using JavaScript. Headers, certificates, reports, crontabs and IP ranges you paste or drop are processed on your device. They are never sent to this site or anyone else.

This is enforced, not just promised. Every page is served with a Content-Security-Policy that includes connect-src 'none', which stops scripts on the page from making network requests. You can check it in your browser's DevTools (Network tab and response headers).

The one exception is What Is My IP (and /ip). It has to run on the server, because only the server can see the address you connect from. It reads your IP and the approximate location the hosting provider attaches to the request, returns them to you, and stores or caches nothing.

The hosting provider (Vercel) may keep standard web server logs, such as IP address, user agent and requested URL, for security and operations. Tool input is never part of those logs, because it never leaves your browser.

No cookies are set and there is no analytics or tracking. If that changes, for example if privacy-respecting ads are added to cover hosting costs, this page will be updated first.
